> [!problem] Question 1
> Show that if $h, h': X \to Y$ are homotopic and $k,k':Y \to Z$ are homotopic then $k \circ h$ and $k' \circ h'$ are homotopic.

***Proof:*** Let $h,h':X\rightarrow Y$ be homotopic and $k,k':Y \to Z$ be homotopic. Since $h\simeq h'$, there exists some continuous map $F:X\times I\rightarrow Y$ with $F(x,0)=h(x)$ and $F(x,1)=h'(x)$. Similarly, because $k\simeq k'$, there exists some continuous map $G:Y\times I\rightarrow Z$ with $G(y,0)=k(y)$ and $F(y,1)=k'(y)$.

Now let $H(x,t)=G(F(x,t), t)$. $$\begin{align} H(x,0) &= G(F(x,0),0) = G(h(x),0)=k(h(x))=&k\circ h \\ H(x,1)&=G(F(x,1),1) = G(h'(x),1)=k'(h'(x))=&k'\circ h'\end{align}$$Since $H$ is built from the composition of continuous functions, it must be continuous, so $H$ is a homotopy and thus $k \circ h$ and $k' \circ h'$ are homotopic.

> [!problem] Question 3
> A subset $A$ of $\mathbb{R}^n$ is said to be **star convex** if for some point $a_0$ of $A$, all the lines segments joining $A$ to other points of $A$ lie in $A$.
> 1. Find a star convex set that is not convex.
> 2. Show that if $A$ is star convex, $A$ is simply connected.

An example of a set that is star convex but not convex is $A=[0,2]\times [0,1]\cup [1,2]\times [1,2]\in\mathbb R^2$. This forms an L-shaped region, so if you chose a point $a_0$ in the lower right corner (inside of $[1,2]\times [0,1]$) each line segment between $a_0$ and any other point in $A$ lies entirely within $A$.

***Proof:*** Let $A$ be star convex, so for some $a_0\in A$ each line segment connecting $a_0$ with $b_0$ for all $b_0\in A$ lie entirely within $A$. We must show $A$ is simply connected.

Let $x,y\in A$. Since $A$ is star convex, there exists some $a_0\in A$ that is connected to both $x$ and $y$ via some line segment. Then $x$ and $y$ must be connected by this intermediate point $a_0$ so $A$ is path connected. Now let $f:[0,1]\rightarrow X$ be a loop that starts at a point $x_0$. Then we can define the following homology: $$H(s,t)=(1-t)f(s)+tx_0$$So for each fixed $s$, the point $H(s,t)$ lies on the line segment between $f(s)$ and $x_0$. This is a continuous homotopy. Since $A$ is path connected and we can build a continuous homotopy, it must be simply connected.
